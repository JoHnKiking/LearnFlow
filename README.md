# LearnFlow - 沉浸式技能学习伴侣

## 📌 项目简介

LearnFlow 是一款创新的技能学习应用，通过像素风格的界面设计和趣味化的游戏化机制，让学习变得更加有趣和高效。应用结合了技能树学习路径、可爱的数字宠物陪伴、迷你游戏奖励系统等多种功能，为用户打造沉浸式的学习体验。

## 🎯 核心功能

### 📊 首页概览
- **学习统计展示**: 实时显示学习时长、技能进度等数据
- **进度可视化**: 直观的进度条展示学习成果
- **快捷操作**: 快速进入学习、查看笔记等功能

### 🎮 技能树学习
- **树形结构展示**: 清晰的技能学习路径可视化
- **学习节点**: 每个技能节点包含学习资源链接
- **体力消耗机制**: 每次学习消耗10点体力
- **进度跟踪**: 实时记录和保存学习进度

### 🐾 数字宠物陪伴
- **三种怪物类型**: 
  - 💫 活力型：能量消耗减半
  - ✨ 沉稳型：体力上限增加10
  - 🌟 叛逆型：游戏奖励翻倍
- **体力系统**: 消耗体力学习，游戏恢复体力
- **能量系统**: AI对话消耗能量
- **等级成长**: 通过学习获得经验值升级

### 🎲 迷你游戏恢复
- **数独游戏**: 经典的9×9数独挑战
- **推箱子游戏**: 完成3关即可获得奖励
- **每日限制**: 每天可玩3次游戏
- **体力恢复**: 通过游戏恢复学习消耗的体力

### 📝 学习笔记
- **笔记记录**: 随时记录学习心得和知识点
- **笔记管理**: 查看、编辑历史笔记
- **时间戳**: 记录笔记创建时间

### ⏱️ 番茄钟专注
- **专注计时**: 多种时长选项（15/25/30/45/60分钟）
- **任务管理**: 添加和管理学习任务
- **完成标记**: 任务完成状态记录

### ❓ 帮助与反馈
- **使用指南**: 详细的功能说明
- **问题反馈**: 提供常见问题示例
- **联系支持**: 获取技术帮助

## 🛠️ 技术栈

### 移动端
- **框架**: React Native + Expo 54
- **路由**: Expo Router 6.0 (文件系统路由)
- **语言**: TypeScript 5.9
- **状态管理**: React Hooks + Context API
- **本地存储**: AsyncStorage 2.2
- **UI组件**: 像素风格自定义组件库
- **SVG支持**: react-native-svg 15.12
- **网络请求**: Axios 1.6
- **WebView**: react-native-webview 13.15

### 服务端
- **框架**: Node.js + Express
- **语言**: TypeScript
- **数据库**: MySQL 8.0
- **认证**: JWT令牌认证
- **密码加密**: bcrypt
- **AI集成**: 大语言模型服务

## 🚀 快速开始

### 环境要求
- Node.js 16.0+
- npm 或 yarn
- Expo CLI
- MySQL 8.0+ (服务端)

### 启动移动端
```bash
cd mobile
npm install
npm start
```

### 启动服务端
```bash
cd server
npm install
npm run dev
```

### 运行应用
1. 手机安装 Expo Go 应用
2. 扫描终端显示的二维码
3. 或使用模拟器运行

## 🔧 核心机制

### 体力系统
- **上限**: 根据怪物类型 100-110
- **恢复**: 每日凌晨5点自动恢复满值
- **消耗**: 学习资源消耗10点
- **获取**: 完成游戏获得奖励

### 游戏系统
- **每日限制**: 3次/天
- **数独**: 完成一局获得奖励
- **推箱子**: 完成3关获得奖励
- **奖励**: 体力值 + 能量Π

### 怪物特性
| 类型 | 特殊能力 | 适用场景 |
|------|---------|---------|
| 活力型 | 能量消耗减半 | 经常使用AI对话 |
| 沉稳型 | 体力上限+10 | 长时间连续学习 |
| 叛逆型 | 游戏奖励翻倍 | 喜欢玩小游戏 |
